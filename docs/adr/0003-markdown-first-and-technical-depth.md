# 0003. 순수 마크다운 집필 및 엔지니어링 실측 데이터 중심 심층 분석 전환

피상적인 요약글에서 벗어나 독보적인 전문성을 확보하기 위해, 해외 3사의 실측 계측 데이터(0-100km/h 가속, 100-0km/h 제동거리, 고속 순항 실내 소음 dBA, 75mph 고속도로 실연비)와 파워트레인·섀시 엔지니어링 메커니즘을 상세히 다루는 심층 분석 체계로 전환한다. 또한 본문 소스코드를 복잡하게 만드는 인라인 HTML 대신, 티스토리 마크다운 에디터와 완전히 호환되는 순수 마크다운(Pure Markdown)을 표준 출력으로 채택하고, 시각적 스타일은 티스토리 스킨 CSS가 표준 마크다운 태그(테이블, 인용구, 헤더)를 매거진 스타일로 자동 스타일링하도록 일원화한다.
